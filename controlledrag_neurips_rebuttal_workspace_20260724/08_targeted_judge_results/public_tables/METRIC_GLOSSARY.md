# Metric glossary

| Metric | Definition | Direction |
| --- | --- | --- |
| system contrast | paired baseline minus HCPC-v1 score | sign gives ordering |
| difference in contrasts | context contrast minus answer-only contrast | magnitude gives input sensitivity |
| AP | faithful-positive ranking precision across recall | higher is better |
| Spearman | score-label rank association | higher is better |
| balanced accuracy | average class recall | higher is better |
| F1 | harmonic mean of precision and recall | higher is better |
| Brier | squared score-probability error | lower is better |
