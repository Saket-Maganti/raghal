# Existing Analyses

Prompt 03 contains fixed-output-only uncertainty, metric-calling,
threshold-transfer, Pareto, cost-weight, and coverage analyses.

- `EXISTING_ANALYSIS_SUMMARY.md` gives the safe interpretation.
- `METRIC_IMPLEMENTATION_AUDIT.md` documents implementation semantics.
- `STABILITY_CLASSIFICATION.csv` separates stable, conditional, and
  unresolved claims.
- `scripts/analyze_prompt03_existing_outputs.py` reproduces the derived tables.
- `results/` stores hashes, manifests, and machine-readable results.

No model inference is performed.
