# Clarity Material

Prompt 04 converts the verified Prompt 1–3 evidence into reviewer-facing
explanations and bounded practitioner guidance. These files are building
blocks, not a final rebuttal, and use no new model result.

- `EXPERIMENT_EVIDENCE_MATRIX.md`: experiment-cell provenance and strength.
- `METRIC_DICTIONARY.md`: plain and implementation-level metric definitions.
- `SEVEN_AXIS_RATIONALE.md`: rationale and limits of the disclosure framework.
- `FIGURE_2_PLAIN_LANGUAGE_EXPLANATION.md`: three explanation lengths.
- `SCOPE_AND_GENERALIZATION_STATEMENT.md`: method versus numerical scope.
- `CONTROLLEDRAG_DECISION_PROTOCOL.md`: operational practitioner procedure.
- `REBUTTAL_READY_CLARITY_BLOCKS.md`: concise drafting components.

All claims remain subject to `01_provenance/P0_INTEGRITY_GATE.md`.
