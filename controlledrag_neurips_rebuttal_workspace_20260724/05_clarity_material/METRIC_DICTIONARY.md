# Metric Dictionary

## Scoring and evaluation metrics

| Metric | Plain definition | Implementation; input → output | Range / direction | Aggregation / threshold | Package evidence | Common misinterpretation | Paper location |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Legacy DeBERTa proxy | How strongly an answer sentence matches the label “entailment” in a zero-shot label call | Answer sentence only → candidate-label probability; retrieved context is not consumed | `[0,1]`; higher is treated as more faithful | Mean across period-split answer segments; `<0.5` labeled hallucinated; empty segmentation returns 1.0; failures contribute 0.5 | `transformers` pipeline; model ID `cross-encoder/nli-deberta-v3-base`; exact revision not locked | It is not context-conditioned entailment merely because a premise argument exists in the wrapper | Setup; fixed-generation metric fragility; supplement implementation |
| Legacy second NLI proxy | A second answer-only zero-shot entailment-label score | Whole answer only → entailment label probability in default `roberta-large-mnli` branch | `[0,1]`; higher treated as more faithful | One answer-level value; `<0.5` labeled hallucinated; empty answer returns 1.0 | `transformers`; exact package/model revision not locked | It is not a universal NLI ground truth, and the historical fallback can change the requested backend | Setup; metric fragility |
| RAGAS-style judge | A custom local judge’s estimate that the answer is supported by the supplied context | Truncated question + retrieved context + answer prompt → parsed scalar | Clamped to `[0,1]`; higher is more faithful | One row-level scalar; JSON preferred, numeric fallback, otherwise 0.0 | `langchain-ollama>=0.1`; exact local model build not locked | It is not the official `ragas` package and not human ground truth | Setup; metric fragility; human calibration |
| Context-conditioned NLI | Entailment probability when retrieved context is explicitly the premise and answer sentences are hypotheses | Context (2,048 chars) + answer sentence → pair-tokenized entailment probability | `[0,1]`; higher is more faithful | Mean across sentences; pair truncation at 512 tokens; empty/failed rows missing | Transformers model IDs recorded; exact weights/runtime not locked | The calling convention is more direct semantically but is not proven universally correct | Figure 2; scorer-input-format paragraph; supplement |
| CCS | A diagnostic of internal coherence among retrieved context chunks | Retained chunk embeddings → mean minus standard deviation of off-diagonal pairwise cosine similarities | Theoretical `[-2,1]`; higher means more mutually coherent context; `-1` is also an implementation failure sentinel | One query-level value; cell-specific summaries and matching constraints | NumPy plus the cell’s embedding model; exact historical revisions vary | CCS is not a faithfulness oracle and high coherence may still support a wrong answer | ControlledRAG/context-structure discussion; matched-context audit |
| Mean retrieval similarity | Average semantic similarity between the query and each retained context chunk | Query and retained-chunk embeddings → mean cosine similarity | `[-1,1]`; higher means more query-similar context; `-1` may signal failure | Mean across retained chunks | NumPy plus the cell’s embedding model | Similarity is not the same as coherence or answer support | Setup; matched-context audit |
| Answer-span indicator | Whether any normalized gold-answer alias appears literally in retrieved context | Lowercased, punctuation-stripped gold aliases + context → binary match | `{0,1}`; 1 means at least one alias is found | Any-alias lexical match per query; rates aggregate rows | Artifact string-normalization code | It is a lexical diagnostic, not proof that the context entails the answer | Matched-context span diagnostic; supplement |
| Raw agreement | Fraction of two independent labels that match exactly | Two pre-adjudication categorical label vectors → proportion equal | `[0,1]`; higher is more agreement | Exact equality; categories retained | NumPy 2.4.4 in Prompt 03 | It must not use adjudicated labels | Human calibration |
| Cohen’s kappa | Chance-adjusted categorical agreement between the two raters | Two pre-adjudication categorical label vectors → unweighted nominal kappa | Conventionally `[-1,1]`; higher is greater beyond-chance agreement | No weighting; all observed categories retained | scikit-learn 1.8.0 | Kappa is not scorer accuracy and does not pool the two slices | Human calibration; supplement |
| Spearman correlation | Whether scorer and adjudicated human ordering move together monotonically | Scorer values + adjudicated ordinal labels → rank correlation | `[-1,1]`; higher positive is closer ordering | Separate by slice; `n=99` map is 0/0.5/1 | SciPy 1.17.1 | A slice-specific correlation does not establish a universally best scorer | Human calibration |
| Pearson correlation | Linear association between two continuous score vectors | Paired scores → linear correlation | `[-1,1]`; magnitude is linear association | Complete paired finite rows | SciPy 1.17.1 | Low correlation is disagreement, not proof that either scorer is correct | Metric fragility |
| AUROC | Probability-like ranking measure comparing faithful and hallucinated cases across all thresholds | Faithful-positive binary labels + scorer values → ROC area | `[0,1]`; higher is better ranking; 0.5 is chance under standard assumptions | `faithful=1`; requires both classes | `sklearn.metrics.roc_auc_score`, scikit-learn 1.8.0 | It is not thresholded accuracy or calibrated probability | Human calibration, `n=100` |
| Average precision | Precision averaged at score-induced recall changes for the faithful-positive class | Faithful-positive binary labels + raw faithfulness scores → non-interpolated sklearn AP | `[0,1]`; higher is better; depends on prevalence | `sklearn.metrics.average_precision_score`; no score inversion; locked for separate `n=100` slice | scikit-learn 1.8.0 | Do not substitute stale manual “AUPRC,” compare across different prevalences casually, or headline the `n=99` four-negative sensitivity | Human calibration, `n=100`; supplement |
| Paired percentile bootstrap CI | Empirical uncertainty interval obtained by resampling paired rows | Paired rows + statistic → 2.5th/97.5th bootstrap percentiles | Statistic-native units | 10,000 Prompt 03 resamples; invalid single-class binary resamples omitted and counted | NumPy/Pandas/SciPy/scikit-learn versions in run manifest | A CI describes sampling sensitivity of the fixed panel, not broader domain coverage | Figure 2; human calibration; supplement |
| Paired Wilcoxon statistic | Rank-based test of whether paired differences are centered away from zero | Paired cell values → Wilcoxon statistic and convention-specific p-value | Statistic depends on `n`; smaller p means less compatibility with the tested null | Paired rows only; sidedness must be stated | SciPy; exact historical version not locked | It is not an effect size, and changing sidedness or zero handling changes the p-value | Matched-context audit; scaled per-seed supplement |
| Threshold recovery index | Descriptive gain/recovery under a fixed threshold rule | Fixed dataset/tau cell → recovery value | Unbounded descriptive index; higher is better and values may be below 0 or above 1 | 5 datasets × 5 tested taus | Fixed recovered output; deterministic Prompt 03 summary | It is not a probability and the grid does not prove universal transfer | Threshold-transfer section |
| Pareto frontier status | Whether another tested system is no worse on every objective and better on at least one | Faithfulness (maximize), latency and indexing time (minimize) → nondominated flag | Boolean within each dataset/tested set | Point estimates only; three objectives | Deterministic Prompt 03 arithmetic | Frontier membership is not statistical dominance and may change with objectives/systems | Cost-aware section |
| Cost utility | Illustrative scalarization of faithfulness and amortized time | `faithfulness - λ × (latency_s + indexing_s/query_volume)` | Unbounded; higher is better | Tested `λ` and query volumes only | Deterministic Prompt 03 arithmetic | It is not a universal economic value function | Cost-aware section and decision guidance |

## Required naming

- Use “legacy answer-only zero-shot label proxy,” not context-conditioned
  entailment, for the historical NLI columns.
- Use “RAGAS-style judge,” never “official RAGAS.”
- Use “average precision” or explicitly state the sklearn AP convention.
- State the human slice and endpoint beside every human metric.
- Use “fixed-context re-encoding,” not fresh retrieval or generation.
