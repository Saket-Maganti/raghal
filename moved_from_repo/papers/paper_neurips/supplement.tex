\section{Pre-Specification}
\label{supp:prereg}

The matched-context, scaled, metric-fragility, threshold-transfer,
noise, cost-aware-baseline, and human-calibration audits were
pre-specified on 2026-04-26 before any results were inspected. The
human-calibration design specified two arms: (i) a stratified
$n{\approx}99$ two-pass adjudicated calibration on the typical row
distribution of the $7{,}500$ Mistral generations, scored as raw
inter-pass agreement, Cohen's $\kappa$, and Spearman correlations of
each scorer against the adjudicated label; (ii) a targeted $100$-row
scorer-disagreement batch constructed from the same $7{,}500$ rows and
designed to stress-test scorer conflict using two independent raters
plus an adjudication step. Both arms are now completed:
\S\ref{supp:human_calibration} reports arm (i) at $n=99$ adjudicated
items, and \S\ref{supp:human_disagreement} reports arm (ii) at $n=100$
two-rater adjudicated items. The pre-specification also fixed: the
matched-pair construction (similarity gap $\leq 0.02$, CCS gap
$\geq 0.20$); the paired Wilcoxon test direction (HIGH$>$LOW); the
$10{,}000$-resample bootstrap for the CI on the mean paired
difference; the Wilson $95\%$ CI on hallucination rates; the seed list
$\{41, 42, 43, 44, 45\}$; the per-seed paired Wilcoxon as the primary
significance test in the scaled audit; the three faithfulness scorers
(DeBERTa proxy, \texttt{roberta-large-mnli} proxy, RAGAS-style) plus
the fixed-context rescore protocol; the $\tau$-sweep range; and the
$200$-query head-to-head sample size. The four follow-up arms were
added after the pre-specified runs as post-hoc robustness checks:
answer-span/control diagnostic, stronger-retriever sanity check,
Qwen$2.5$ second-generator replication, and long-form stress test. We
disclose which experiments are pre-specified
(\texttt{audit\_log.md} sections under ``Pre-Specified'') versus
follow-ups (\texttt{audit\_log.md} sections under ``Follow-Up'') in
the file \texttt{audit\_log.md} shipped at the top level of the
artifact.

\section{Context-Conditioned NLI Rescoring (Subset)}
\label{supp:context_conditioned_nli}

The frozen artifact's DeBERTa-v$3$ and \texttt{roberta-large-mnli}
faithfulness columns are legacy zero-shot label proxies: the answer
sentence is the sequence classified against the labels
entailment / neutral / contradiction with
\texttt{hypothesis\_template="\{\}"}, and the retrieved context is
not consumed by those calls. To make scorer input format an
empirically observable audit axis (not just a disclosure axis), we
rescore a balanced subset of the same fixed-generation rows under a
proper context-conditioned NLI calling convention:
\[
\text{premise} = \text{retrieved context (truncated to 2048 chars)},
\quad
\text{hypothesis} = \text{generated answer sentence},
\]
followed by softmax over
$\{\text{contradiction},\text{neutral},\text{entailment}\}$ and a
mean-over-sentences aggregation matching the legacy proxy aggregation.
The rescoring script is \texttt{scripts/run\_context\_conditioned\_nli\_scoring.py}.

\paragraph{Subset.} $n=200$ paired queries per condition (baseline,
HCPC-v$1$, HCPC-v$2$), so $n=600$ rows total. Subset selection is
deterministic (first $200$ rows by appearance under the original
fix\_03 ordering), so the subset is balanced across conditions but is
not stratified by question domain. Rescoring is performed with both
\texttt{cross-encoder/nli-deberta-v3-base} and
\texttt{roberta-large-mnli} on Apple-silicon MPS without paid APIs.

context-conditioned NLI rescorings (rows 3--4) use the same backbone

\paragraph{Reading.} For both DeBERTa-v$3$ and
\texttt{roberta-large-mnli}, switching from the legacy zero-shot label
proxy to a context-conditioned NLI calling convention on the same
backbone weights changes the sign of the reported baseline$-$HCPC-v$1$
contrast on the same fixed generations. The legacy and
context-conditioned bootstrap CIs are disjoint for both models. The
RAGAS-style judge, which is context-conditioned by construction,
agrees in sign with the legacy proxies but disagrees in magnitude. We
do not claim a uniformly ``correct'' scorer; the table is the audit
point: scorer input format is a real movable quantity in the headline
number.

\paragraph{Alignment with the $n=99$ calibration.} On the
$n=99$ adjudicated calibration items, switching the same DeBERTa-v$3$
and \texttt{roberta-large-mnli} backbones to the context-conditioned
calling convention does \emph{not} improve Spearman alignment with the
adjudicated labels: legacy DeBERTa proxy $\rho=+0.157$ vs.\
context-conditioned DeBERTa $\rho=+0.120$; legacy
\texttt{roberta-large-mnli} proxy $\rho=+0.393$ vs.\
context-conditioned $\rho=+0.224$ (CIs in
\texttt{n99\_alignment\_spearmans.csv}). The result is consistent with
NLI models pre-trained on short premise/hypothesis pairs being
sensitive to long-context input format. This is a calibration finding,
not a recommendation; the contribution is that scorer input format
must be reported and audited, not that any one input format is
preferred.

\paragraph{Subset is not the full table.} This is a $600$-row
subset, not a full $7{,}500$-row rescoring. The scaled audit raw
table in the main paper still uses the full $7{,}500$-row legacy
proxy values; the standardised z-/rank-contrast table
(\S\ref{supp:scorer_standardized}) also uses the legacy proxies. The
context-conditioned subset is a focused empirical demonstration of
the input-format axis, not a replacement for the legacy table.

\section{Self-RAG: Harness-Mismatched Appendix Baseline}
\label{supp:selfrag}

We include Self-RAG~\citep{asai2024selfrag} only as an appendix
baseline because the available Self-RAG harness mismatches the audit's
fixed-context protocol along three dimensions: (i) Self-RAG's
generator emits its own retrieval and reflection tokens, so the
``fixed retrieved context'' assumption used by the matched-context and
metric-fragility audits is not directly satisfied; (ii) Self-RAG's
recommended generator is a fine-tuned Llama-$2$-$7$B variant that does
not coincide with the audited Mistral-$7$B / Qwen$2.5$-$7$B family
and that was OOM-killed on the available T$4$ instance for the
PubMedQA cell, so the partial SQuAD numbers we have are not directly
comparable to the cost-aware head-to-head; and (iii) the
recommended Self-RAG threshold differs from the threshold-transfer
sweep used elsewhere. We report this disclosure here so that future
ControlledRAG-style audits can budget for a matched Self-RAG harness;
we explicitly do not generalize from these mismatched runs to Self-RAG
overall.

\section{Coherence vs.\ Generic Retrieval Noise}
\label{supp:noise}

The noise audit uses the matched-context construction as a backbone
and replaces $1/3$, $2/3$, or $3/3$ of the retrieved chunks with one
of two noise types: random off-topic passages and coherence-preserving
uninformative passages drawn from the same topic distribution that do
not contain the answer.

\section{Threshold Transfer: Full Sweep}
\label{supp:threshold}

\noindent\emph{Naming.} Tables in this section use the prior-work
names HCPC-v$1$ ($=$ aggressive-refinement) and HCPC-v$2$
($=$ gated-refinement); see main paper \S 3.

The main paper reports a per-tune-dataset summary
(diagonal recovery, off-diagonal mean, gap) at each tune dataset's
selected $\tau^\ast$. The full $5 \times 5$ per-cell transfer matrix at
each tune dataset's $\tau^\ast$ is reproduced below; the per-$\tau$
sweep over $\{0.3, 0.4, 0.5, 0.6, 0.7\}$ for each dataset is in the
artifact's \texttt{results/revision/fix\_04/} directory.
Recovery is the dimensionless normalized contrast
\[
R_\tau(d)=
\frac{\mathrm{faith}_{\mathrm{gate},\tau}(d) -
      \mathrm{faith}_{\mathrm{HCPC}\text{-}v1}(d)}
     {\mathrm{faith}_{\mathrm{baseline}}(d) -
      \mathrm{faith}_{\mathrm{HCPC}\text{-}v1}(d)}.
\]
It is useful for asking whether a tuned threshold transports, but it is
not a direct utility measure: when the denominator is small or negative,
the sign can be counterintuitive and values can exceed $1$.

\section{Completed Targeted Scorer-Disagreement Evaluation ($n=100$)}
\label{supp:human_disagreement}

The targeted scorer-disagreement evaluation is the adversarial arm of
the human-calibration pre-specification. It is \emph{separate} from the
$n=99$ typical-row calibration in \S\ref{supp:human_calibration}: items
are constructed to maximise scorer disagreement rather than to
estimate population-level faithfulness. Both raters labelled all $100$
items and adjudication resolved the $12$ rater-rater disagreements.

\paragraph{Batch construction.}
Rows are sampled from the $7{,}500$ Mistral generations in the scaled
audit. We compute the absolute disagreement between the legacy DeBERTa
proxy and the context-conditioned RAGAS-style score and stratify the
batch across three disagreement types:
\begin{enumerate}
    \item \textbf{DeBERTa high / RAGAS-style low.}
    \item \textbf{RAGAS-style high / DeBERTa low.}
    \item \textbf{Near-threshold disagreement} around the $0.5$
        decision boundary.
\end{enumerate}
The batch is also balanced across baseline / HCPC-v$1$ / HCPC-v$2$.
Items already used in the $n=99$ calibration are excluded.

\paragraph{Annotation protocol.} Two independent raters assigned one
of \texttt{faithful}, \texttt{hallucinated}, or \texttt{unclear} using
only the retrieved context, and an adjudication step resolved
disagreements. The protocol artifacts shipped with the review package
are:
\begin{itemize}
    \item \texttt{human\_eval\_final/n100\_disagreement/annotation\_batch\_disagreement\_100.csv}: the merged batch with scorer scores, rater $1$, rater $2$, and adjudicated labels.
    \item \texttt{human\_eval\_final/n100\_disagreement/human\_eval\_rater1.csv} and \texttt{human\_eval\_rater2.csv}: independent rater files used during labelling.
    \item \texttt{human\_eval\_final/n100\_disagreement/human\_eval\_adjudicated.csv}: per-row file with rater $1$ label, rater $2$ label, adjudicated label, adjudicated confidence, and adjudication notes; all $12$ rater-rater disagreements carry meaningful adjudication notes.
    \item \texttt{human\_eval\_final/n100\_disagreement/human\_eval\_adjudication\_template.csv}: the reconciliation template used during adjudication.
\end{itemize}

\paragraph{Agreement and label distribution.}
The two raters labelled all $100$ items
($100/100$ for each rater); the adjudicated label set covers all
$100$. Raw inter-rater agreement is $0.88$ ($88$ of $100$
exact-match), Cohen's $\kappa=0.721$. The rater $1$ distribution is
$74$ \texttt{faithful} / $26$ \texttt{hallucinated} / $0$
\texttt{unclear}; the rater $2$ distribution is $70$ /
$20$ / $10$ (rater $2$ used the \texttt{unclear} option, rater $1$
did not). The adjudicated distribution is
$74$ \texttt{faithful} / $26$ \texttt{hallucinated} / $0$
\texttt{unclear}.

Table~\ref{tab:supp:disagreement_alignment} reports per-scorer
correlation, AUROC, and AUPRC against the adjudicated faithful /
hallucinated label, with $1{,}000$-resample bootstrap $95\%$ CIs from
\texttt{scripts/analyze\_human\_disagreement\_labels.py}.

\paragraph{Reading.} On this targeted disagreement-focused slice,
\texttt{roberta-large-mnli} aligns best with adjudicated labels by all

strongest. The combination supports the ControlledRAG claim that
scorer ranking is evaluation-slice dependent, not a global ordering.

\paragraph{Caveat.} The $n=100$ batch is constructed to be adversarial
for any single scorer (rows where the legacy DeBERTa proxy and the
RAGAS-style judge disagree most). It is therefore not a population-level
faithfulness estimate and not a substitute for the $n=99$ random-sample
calibration. The two slices answer two different audit questions, and
ControlledRAG asks for both to be reported.
