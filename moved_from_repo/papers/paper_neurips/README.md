# Review Package README

This directory contains the NeurIPS-style review version of:

> When Retrieval Quality Decouples from Faithfulness: A Pre-Registered
> Audit of RAG Evaluation

The paper frames ControlledRAG as a reusable audit protocol and
prescriptive minimum reporting standard for RAG faithfulness claims. The
central claim is methodological: RAG faithfulness evidence should be
reported across seven axes rather than reduced to one score.

## Files

- `main.tex`: main paper source.
- `supplement.tex`: supplementary material source.
- `references.bib`: bibliography.
- `SOURCE_TRACE.md`: claim-to-source mapping.
- `CLAIMS_AUDIT.md`: allowed and forbidden claim language.
- `SUBMISSION_CHECKLIST.md`: build, anonymity, and claim-hygiene checks.
- `audit_log.md`: pre-registered vs follow-up experiment mapping.

## Review Artifact Policy

The review version is anonymized. Public release, benchmark,
repository, and archive links are intentionally omitted and will be
released upon acceptance.
